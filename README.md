# Library Management System

A comprehensive library management system with user and admin functionalities.

## Features

### User Features:
- User registration and login
- Search for books by title, author, ISBN, or category
- View book details and availability
- Borrow books with real-time cost calculation
- Track borrowed books
- View notifications

### Admin Features:
- Add, update, and delete books
- Manage book inventory
- Approve/reject borrow requests
- View all users
- Manage notifications

## Tech Stack

### Frontend:
- HTML5 (Semantic)
- CSS3 (Custom styles)
- JavaScript (Vanilla)
- Local Storage for notifications

### Backend:
- Node.js
- Express.js
- MongoDB with Mongoose
- JWT Authentication
